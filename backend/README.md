# `backend/` — API server

**Purpose:** everything the browser should not do directly: validation, database access,
business rules, and calling the AI modules.

- **Stack:** Python, FastAPI, SQLAlchemy 2.0, Alembic, Pydantic, psycopg (PostgreSQL driver).
- **Contains (later phases):** `app/` (routers, services, models, schemas), `alembic/`
  (migrations), `tests/`, and a pinned dependency file.
- **Must NOT contain:** ML training code (that lives in `../ai/`), frontend code, or
  real credentials (config comes from `.env` via a settings module).

**Status:** empty — not created yet (planned for milestones M1–M2 in
[`../docs/roadmap.md`](../docs/roadmap.md)).

Commands that will be used later:
```bash
python -m venv .venv                       # from the repo root
.venv\Scripts\activate                     # Windows: activate the venv
pip install fastapi uvicorn sqlalchemy alembic "psycopg[binary]" python-dotenv pytest
uvicorn backend.app:app --reload           # run on http://localhost:8000
```
The interactive API docs will be at `http://localhost:8000/docs` (auto-generated by FastAPI).
